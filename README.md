# About Me

개발자로서의 일, 경험, 가치관, 목표, 선호, 의사결정 기준을 정리한 개인 기록 저장소다.

ChatGPT와의 50개 질문·답변을 통해 정리했으며, 개발자로서의 업무 방식뿐 아니라 커리어 방향, 생활 방식, 장기 목표, AI와의 협업 기준까지 함께 담고 있다.

## Purpose

이 저장소는 이력서나 포트폴리오를 위한 소개 자료라기보다, 시간이 지나도 나의 생각과 기준을 돌아볼 수 있도록 기록하고 관리하기 위한 공간이다.

필요한 경우 AI와 협업할 때 개인적인 맥락과 선호를 전달하기 위한 참고 자료로도 활용한다.
